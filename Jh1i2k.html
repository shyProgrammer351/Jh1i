문제

아래 설명된 의미에 해당하는 용어를 쓰세요 
 y = f( x )에서 f에 해당하며, x값을 전달받아 처리하고 그 결과값을 y로 반환  

 메서드 내에서 자기자신 메서드를 호출하는 메서드  

 y = f( x )에서 x에 해당하며, 전달한 입력과 전달받은 입력은 별개의 변수 공간을 사용  

 함수 내부에서만 사용할 수 있는 변수이며, 함수 호출시 공간을 확보하고 함수 종료시 소멸  

 메서드 종료시 제어흐름이 메서드를 호출했던 곳으로 되돌아감  

 비교연산자로 왼쪽 값이 오른쪽 값보다 크면 참을 반환하고 아니면 거짓을 반환  

 조건식이 참이면 해당 명령문을 실행하는 선택문  

 앞에 제시된 조건식이 모두 거짓이면 해당 명령문을 실행하는 선택문  

 다른 패키지 클래스를 가져오기  

 입력, 날짜, 등 유용한 클래스를 제공하는 패키지  

 데이터를 읽어오는 기능을 제공하는 클래스  

 클래스 객체를 메모리에 생성  

 키보드와 같은 표준 입력  

 리소스 닫기 메서드  

 주어진 내용을 모니터에 출력하는 메서드  

 정수형 데이터를 읽어오는 메서드
