문제

아래 설명된 의미에 해당하는 용어를 쓰세요 
 메서드 종료시 반환값 없이 호출했던 곳으로 되돌아가는 메서드를 의미  

 -2, -1, 0, 1, 2 등의 정수를 표현하는 기본자료형  

 초기식, 조건식, 증감식으로 구성되고, 조건식이 참일 때마다 해당 명령문을 실행하는 반복문  

 조건식이 참이면 해당 명령문을 실행하는 선택문  

 앞에 제시된 조건식이 모두 거짓이면 해당 명령문을 실행하는 선택문  

 비교연산자로 두 변수값이 같으면 참을 반환하고 다르면 거짓을 반환  

 증가연산자로 연산자의 왼쪽 변수값에 1만큼 더한 값을 왼쪽 변수 공간에 저장  

 감소연산자로 연산자의 왼쪽 변수값에 1만큼 뺀 값을 왼쪽 변수 공간에 저장  

 클래스 객체를 메모리에 생성  

 키보드와 같은 표준 입력  

 리소스 닫기 메서드  

 정수형 데이터를 읽어오는 메서드  

 비교연산자로 왼쪽 값이 오른쪽 값보다 크면 참을 반환하고 아니면 거짓을 반환  

 비교연산자로 왼쪽 값이 오른쪽 값보다 작으면 참을 반환하고 아니면 거짓을 반환  

 비교연산자로 왼쪽 값이 오른쪽 값보다 크거나 같으면 참을 반환하고 아니면 거짓을 반환
